PROJECT PROPOSAL / 01

面向 Capability Discovery 的 Embodied RSI

让机器人从失败中发现完成任务所缺少的条件，提出并验证新的 preparatory action，并持续改进自己发现和学习新能力的方式。

Background & objective

现有 Vision-Language-Action（VLA）models 主要依赖示范学习。面对未覆盖的物理条件或操作失败，模型往往反复调整已有动作，难以主动发现并建立完成任务所需的新条件。想象驱动训练可以扩展经验，但生成的未来可能偏离真实物理，且固定的数据选择流程未必越来越会学习。

项目目标：以 π0.5 为 action backbone，让 agent 从交互中形成 belief state，通过 adaptive imagination 推演可能的 preparatory action，通过环境验证其效果，并学习选择更有价值的探索与训练数据。

Methodology

观察与诊断历史观测、动作、任务
提议与想象生成 candidate preparatory actions 及后果
执行与验证评估干预后的技能表现
学习与再选择更新能力及 exploration policy

controller qφ 根据失败历史选择提议、想象或执行；π0.5 action expert πθ 生成 continuous action chunk；action-conditioned world model Wψ 预测图像与本体状态；effect predictor Eω 估计 downstream skill 的 success rate。想象仅用于候选筛选，real environment feedback 负责验证和校正。

Δenable(h,u,k)=Pπ¯(成功∣h,u,k)−Pπ¯(成功∣h,u0,k)−λC(u)

从匹配状态比较干预与对照，固定 skill evaluation policy 并重复采样。其中 h 为失败历史，u 为 preparatory action，u₀ 为对照，k 为技能，π̄ 为固定的 skill evaluation policy，C 为干预 cost。该信号衡量干预整体效果，不自动证明特定物理原因。

用有效和无效分支训练候选提议；借鉴 Agima 的 adaptive imagination 训练离散决策，借鉴 RISE 的 advantage-conditioned flow matching 更新连续动作。world model 由实际转移数据训练和校正。

Architecture

交替决策接口。在每个决策点输入多视角 observation、proprioception、task instruction 和带来源标记的 history。controller 输出 PROPOSE / IMAGINE / EXECUTE / STOP：候选 preparatory action 由操作、目标对象及参数构成，再由 π0.5 生成一个或多个 action chunk。仅 EXECUTE 可驱动环境；imagined observation 必须标注 branch ID，并与预测的 future proprioception 配对。

Belief 与想象。history encoder 生成 belief state，以保留多次交互对隐藏物理条件的证据。world model 接收 history 和候选动作，预测未来图像、robot state 和用于效果估计的 latent；effect predictor 输出后续 skill 的成功概率。latent 不预设可辨识为摩擦等物理量，必须通过真实任务结果检验。

第一版可冻结 π0.5 backbone，分别训练 action / controller adapters，并连接预训练视觉生成器；这是共享上下文的模块化实现，不声称原生 π0.5 已支持图像生成。

Training pipeline

Stage 0 · Skill warm-up。使用 LIBERO demonstrations 及额外基础技能数据训练 πθ 的 action adapter；保留失败轨迹和多视角 observation、proprioception、actions。preparatory action 所需的基本操作必须先具备可执行性；最终测试留出未见过的任务与技能组合。

Stage 1 · Grounded branch data。从训练任务的 failure snapshot 出发，采样多个候选 u 和 no-op / retry 对照。执行每个候选后，用本轮冻结的同一 skill policy π̄ 测试下游技能，重复 seeds 估计 Δenable。记录真实转移、success / failure 及计算与交互成本；失败和无效分支同样保留。仿真可恢复快照，真机须通过可重复初始化近似对照，额外尝试均计费。

Stage 2 · Model pretraining。以真实 transition 监督 Wψ 的 action-conditioned 关键帧与 proprioception 预测；以实际 skill 成败训练 Eω，并对匹配分支学习效果排序。将环境验证后的候选、结果及选择组成 trace，对 controller 的离散 token 做 supervised fine-tuning。latent 可通过未来观测与 skill 结果预测训练；合成帧不能作为真实结果标签。

Stage 3 · Adaptive imagination & policy improvement。冻结当前 rollout snapshots，controller 自适应选择候选数量、想象深度与何时执行；对高价值、存在分歧及随机探索的分支进行环境验证。用环境终局 success、干预收益与 cost 优化 controller 的离散决策（如带 KL 约束的 policy gradient）；借鉴 RISE 将验证或可信短 rollout 的 advantage 分箱，condition πθ 的 flow-matching loss 更新连续动作。image / action head 不直接套用语言 token 的 GRPO。真实轨迹混合 replay，并用新转移周期性校正 Wψ 与 Eω。

Δenable 衡量固定后续 skill 的相对成功率；完整任务 reward 另含 final success 和累计 cost。不能仅以演示时间进度打分，否则必要的 preparatory action 可能被误判为退步。

RSI 闭环

在训练阶段，控制器额外决定哪些失败状态与候选值得验证、哪些经验进入训练。比较不同选择使同一初始策略更新后的表现，将downstream learning gain用于更新控制器。

Rlearn(e)=Jdev(θe+)−Jdev(θbase+)−λC(e)

e 是探索及数据选择；θ⁺e 与 θ⁺base 分别为所选经验和默认采样经验更新后的策略参数；Jdev 在 development tasks 上衡量表现。

外层如何更新 qφ：每轮固定初始 θ、world model 与 effect predictor，让 controller 选择验证哪些分支及哪些数据进入训练，形成 De；对照使用随机或固定规则选择 Dbase。从同一个 θ 复制两个 adapter，各运行相同 K 步更新，得到 θ⁺e 和 θ⁺base。在未参与本轮梯度更新的 development tasks 上比较表现，得到 Rlearn。

将 Rlearn 作为该批次离散探索 / 数据选择 token 的延迟 reward，以带 baseline 的 policy gradient 或组内相对优势更新 qφ；不必对 K 步 optimizer 求导。下一轮使用更新后的 controller 产生数据，并继续更新 action adapter 和模型。为控制成本，第一版可在少量候选批次上做 K 步 adapter 克隆，但需用更长训练检验短期收益是否可靠。

防止自我验证：固定对照的 interaction budget、训练步数、评估模型和重复种子；纳入候选探索、环境验证、模型推理、克隆更新与 development evaluation 的全部成本。保留随机探索比例，避免错误的 world model 排除有效分支。development tasks 用于元训练，最终 test tasks 全程封存。

递归证据：在 held-out tasks 上，从同一 θ₀ 出发，固定 world model、effect predictor、memory 和预算，仅替换早期 qφ₀ 与后期 qφᵣ；比较 learning curve、曲线下面积及达到成功率阈值的交互次数。若后期 controller 稳定提升学习效率，才支持改进机制变强；这仍是待验证的有限任务设定，不代表开放式 RSI 已实现。

实验设计与实施路径

先验证 preparatory action 是否真正提升 skill success rate，再验证 exploration policy 能否跨任务提升学习效率。

Experimental procedure

  1. 基础能力：微调 π0.5，建立抓取、推动、接触等可组合技能；构造 failure trajectories 与 environment transition data。
  2. 发现与验证：从失败快照采集 preparatory action 与对照分支，训练 world model、effect prediction 与候选控制器；测试未见过的条件—技能组合。
  3. 策略自改进：用短想象产生候选、用环境验证关键分支，通过 advantage-conditioned training 更新动作，并训练 controller，并持续校正 world model。
  4. 递归验证：对比早期与后期控制器，固定相同初始策略、world model、记忆和预算，在 held-out tasks 上比较学习效率。

Required data

数据来源与用途
base demonstrationsLIBERO / π0.5 兼容轨迹：images、proprioception、actions 与 task instructions，用于 action warm-up。
failures & interventions自建仿真轨迹：失败历史、candidate preparatory actions、匹配对照、后续技能结果；包含无效干预。
dynamics transitions实际执行的多视角图像、本体状态和动作，用于训练与校正 Wψ 和 Eω。
held-out tasks按失败机制、物体、工具及目标的组合划分训练 / 开发 / 测试，test set 不参与 meta-training。

标准 LIBERO 不直接提供所有隐藏物理条件及干预标签；需要独立扩展任务与数据采集。初期可采用可控物理代理，真实接触机制需额外建模或真机验证。

Evaluation & baselines

指标：full task success rate、有效干预率、环境交互次数、想象与训练计算 cost，以及新任务学习曲线和达到目标 success rate 所需的交互量。

对照：原始 π0.5、直接重试 / 固定搜索、外接反思、RISE 风格自改进、Rollback 风格回溯与分支蒸馏；消融干预收益、belief state、真实校正和学习收益。对齐真实交互及计算预算。

标准 LIBERO 测试沿用现有预处理、等待和步数上限；训练中的 snapshot restoration 及额外测试单独统计，扩展任务单独报告。

Related work

Agima · Train an Imaginative Agent：交替想象与动作，并用任务结果学习自适应推理。

RISE · Self-Improving Robot Policy with Compositional World Model：world model 与价值估计驱动策略更新；原实验的自改进阶段冻结模型与价值网络。

Rollback · Experience Backtracking in World Models：从历史状态回溯分支、对比后果并共同改进 world model 和策略。

ThinkingVLA：统一文字、视觉推理与动作生成。图像推理或分支搜索本身并非本提案的独有创新。

本项目拟验证的区别是：以技能可行性为信号发现 preparatory action，再以跨任务学习收益训练经验选择机制。其新颖性与有效性仍需充分实验及文献核查。
