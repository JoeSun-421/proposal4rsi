RESEARCH PROPOSAL / 01

面向 Capability Discovery 的 Embodied RSI

让机器人从失败中发现新的准备动作，通过环境验证其作用，并持续改进自身发现与学习新能力的方式。

Background

视觉语言动作模型（VLA）通常从示范学习动作。任务条件偏离数据时，机器人可能反复微调失败动作，却不主动改变成功所需的前提。世界模型提供想象，但预测误差会误导搜索；固定训练循环也无法证明系统越来越会学习。

研究问题：agent 能否根据失败证据，在候选空间中发现此前没有纳入计划的 preparatory action，验证它是否提高后续 skill 的可行性，并将多次学习的结果用于改进后续探索？

Contributions

创新点 1 · Learn to enable

用匹配对照下的 skill success 差值监督 preparatory action，发现“先改变什么，原技能才更可能成功”。

创新点 2 · Adaptive grounded imagination

控制器决定想象哪些候选以及是否验证；短想象生成候选，环境交互与成对试验提供监督和世界模型校正。

创新点 3 · Learn to improve

以策略更新后的跨任务 learning gain 为反馈，训练选择实验和数据的 controller，检验后期改进机制能否教会一个相同初始的新策略更快学习。

这是待验证的设计，不将以上点标为首次：Agima、RISE、Rollback 及 ThinkingVLA 已覆盖想象、策略改进、回溯分支或多模态推理的不同部分。

System overview

Observe失败历史与 belief
Imagine候选动作与预测后果
Verify环境对照与 skill 测试
Improve动作、模型与探索策略

π0.5 是连续控制底座；controller 组织推理与训练数据；action-conditioned world model 与 effect predictor 为候选提供可校正的预测。训练阶段有额外的经验选择和对照更新；部署阶段可关闭 learning mode。

METHOD / 02

架构与模型接口

保留 π0.5 action expert，以明确的多模态接口连接 controller、world model 与 effect predictor。

Input / output

令 ht 包含多视角图像 o、本体状态 s、任务 g、已执行动作与结果；区分真实和想象观测。b 是从历史学习出的 belief state，保留对不可直接观测条件的不确定性。

模块InputOutput / 学习目标
qφ controllerh、g、belief、预算离散 operation 与候选 u；测试时决定推演或执行，训练时选择验证与数据。

(ô,ŝ,b̂)=Wψ(h,a)

候选动作首先是模拟输入；只有 EXECUTE 触发真实交互。imagined observation 必须附带 branch ID 和对应的 predicted proprioception，不能与当前实际本体状态混配。

Modify π0.5

  1. 保留预训练 visual-language backbone 和 continuous action expert；增加 history / belief adapter，并给动作条件增加 preparatory action 的结构化 token。
  2. 增加可训练的离散 controller head，输出 PROPOSE、IMAGINE、EXECUTE、STOP 及操作对象、参数；训练时另有选择验证分支与样本的 LEARN mode。
  3. 连接预训练视觉生成 expert，以及 future proprioception / latent prediction head；通过共享上下文交换信息。π0.5 原有图像编码器本身不是图像生成器。
  4. 第一版冻结基础 backbone、分别训练 action 和 controller adapters；world model 与 effect predictor 独立训练。之后再消融共享骨干的联合微调。

这是一种可落地的模块化 agent；并不要求所有模态共用同一个 decoder，也不声称现有 checkpoint 已具备新的输出头。

02 / 05

TRAINING / 03

从失败到可执行的“顿悟”

先建立基础技能与环境监督，再让 agent 学会提出、想象、验证和改进此前未组合过的准备动作。

Stage 0 · Skills

用 LIBERO demonstrations 和补充的独立技能数据对 π0.5 做 action warm-up，构造抓取、推动、接触等技能。记录 observation、proprioception、action、指令和 success / failure。测试保留任务组合；若缺少基础操作数据，不能期望系统凭空学会其物理执行。

xτ=(1−τ)a+τε,LFM=𝔼∥vθ(x,τ,h,u,z)−(ε−a)∥2

a 是示范 action chunk，ε 是高斯噪声，τ 是 flow time，x 是插值噪声动作，vθ 是预测 vector field，z 为后续阶段的 advantage 条件。训练时混合 demonstrations 与通过环境验证的轨迹，避免遗忘。

Stage 1 · Ground

从训练任务的 failure snapshot 采样多个候选 u 与对照 u₀。环境执行准备动作，再以本轮冻结的 π̄ 测试相同的后续 skill，重复采样估计成功率；保留失败、无效和成功分支。

Δenable=Pπ̄(success∣h,u,k)−Pπ̄(success∣h,u0,k)−λC(u)

Δenable 是干预的整体效果，不单独证明某个隐藏物理因子。仿真中可从同一快照分支；真机以可重复初始化近似匹配，记录随机种子或试验条件，并将所有试探和重置纳入预算。验证条件不足时保留不确定性，不把模型预测当作真值。

Stage 2 · Learn

以真实 action-conditioned transitions 训练 Wψ 的关键帧、future state 和 future outcome 预测；以真实 skill success 标签训练 Eω，并以匹配分支训练排序。用已验证的候选—后果—选择轨迹对 controller 做 trace SFT。

Lworld=Lvisual+λsLstate+λbLfuture,Leffect=BCE(Eω(b,k),y)

Lvisual 可为预训练生成器的 flow / diffusion objective；Lstate 监督本体状态，Lfuture 监督后续可观测量。未监督 latent 不自动等于摩擦系数。视觉相似度与干预排序准确度须分别测量。

Stage 3 · Improve

controller 选择候选、想象深度及何时执行；对高价值、模型分歧和随机探索的候选进行环境验证。将真实 success、Δenable 和成本构成的 reward 转为优势 A，训练 controller 的离散决策；对 continuous action 用 RISE 风格 advantage-conditioned flow matching，更新 πθ。

Lcontroller=LSFT−β𝔼[A⋅logqφ(d∣h)]+ηDKL

LSFT 是已验证 trace 的交叉熵，d 是 controller 决策 token，DKL 约束策略漂移。Agima 的 RL 直接优化语言 token，图像不受直接 RL loss；连续动作 flow 不能直接套用该 GRPO。模型合成结果只能做筛选或受控辅助监督，环境反馈负责校准。

能力出现的可检验路径：基础动作可执行 → 分支中发现可行性提升 → 将有效干预及无效尝试训练成可迁移的选择能力 → 对新条件组合提出并验证准备动作。一次成功属于任务求解，并不单独证明 RSI 或隐藏物理因果理解。

03 / 05

RECURSION / 04

RSI：让改进机制本身得到训练

内层提高行动能力；外层根据学习结果，更新“如何选择实验和训练数据”的策略。

Outer loop

  1. Choose。第 r 轮冻结 rollout snapshots，qφr 根据历史 H 选择 failure states、验证候选与数据子集，得到实验 e。
  2. Verify。在指定预算内从环境收集 De；固定规则或随机选择形成 Dbase。保留真实失败与随机验证，防止 W 的盲区自我强化。
  3. Compare。从完全相同的 θ 复制两个轻量 adapter，在相同 K 步和匹配预算下分别更新；world model、effect predictor、评估协议保持一致。
  4. Meta-update。在未参与本轮梯度更新的 development tasks 衡量两者表现，使用 Rlearn 更新 qφ 的 LEARN decisions。下一轮使用新 controller 产生训练经验。
θe+=UK(θ,De),θbase+=UK(θ,Dbase)
Rlearn(e)=Jdev(θe+)−Jdev(θbase+)−λC(e)

UK 是固定 K 步优化，Jdev 是 development performance，e 是验证与数据选择，C(e) 包含探索、验证、世界模型推理、克隆更新和评估成本。预算需要可计量并与对照对齐。

Train controller

将学习收益分配给该批次的离散选择，以带 baseline 的 policy gradient 或组内相对优势训练 controller；不必对优化器反向传播。

∇φJ≈𝔼[(Rlearn−b)∇φlogqφ(e∣H)]

b 是 reward baseline，不是 belief state；H 是跨轮训练历史。K 步 adapter 克隆仅是未来收益的近似，要复验更长训练；多 seeds 和独立 development tasks 可以降低 reward 噪声。development 用于元训练，最终 test tasks 全程封存。

Claim boundary

固定的更新程序让 θ 变强，证明策略自改进；qφ 因学习结果而改变探索与数据选择，并在新任务上提高同一起点策略的学习效率，才支持“改进机制本身变强”。这仍是有限任务和预算下的 RSI 实验假设，并不等于无限、开放式自我改进。

EVALUATION / 05

实验、数据与成功标准

从能力、机制与跨任务学习效率三个层次验证；所有对照按环境交互和计算成本匹配。

Datasets

数据来源 / 字段 / 用途
Demonstrationsphysical-intelligence/libero 官方示范：instruction、images、proprioception、actions；预热 π0.5。补充独立 preparatory skill 示例。
Failure / branch自建扩展环境：failure history、snapshot ID、u 与 u₀、actions、后续 skill success、成本；用于 Δenable 和 controller trace。
World transitions真实仿真 / 机器人动作及多视角后果；用于训练 W、E 和真实校正，包含失败和低质量干预。
Task splits按机制、对象、工具与任务组合划分 train / development / held-out test；另做机制、外观、工具和条件组合的分布外评估。

标准 LIBERO 不自带完整的隐藏物理条件或干预标签。新建扩展任务必须提供可验证的动力学；显式摩擦代理只代表代理环境，不证明模拟了真实油膜 / 布料。

Experiments

  1. 基础可靠性。分开测 π0.5 基础 skill、preparatory skill 和 effect predictor 的校准；防止低层控制失败掩盖高层发现。
  2. 发现能力。在新组合下记录 full-task success、有效干预率、尝试次数、无效干预与不必要操作；评估相似外观、不同原因及没有有效工具的情况。
  3. 想象是否有用。比较 action-only、固定分支预算、自适应想象、无环境校正与真实校正；测 candidate-ranking accuracy、短 rollout 误差及模型偏差随深度变化。
  4. 策略改进。同预算比较 π0.5、固定 / 随机选择、RISE 风格训练、Rollback 风格回溯蒸馏，以及外接 VLM 反思；分别消融 belief、Δenable、真实监督、随机探索。
  5. RSI 迁移。固定新学生 θ₀、W、E、memory、交互预算与更新步数，仅替换早期 φ₀ / 后期 φᵣ；在 held-out tasks 比较学习曲线、AUC 与达到预设 success 阈值所需交互。对该 test 不训练、不调参。

Budget & validity

报告 task success 及置信区间、每任务 / seed 曲线、真实环境 steps、snapshot 恢复次数、world-model calls、生成帧、训练 FLOPs / wall time、GPU 及人工示范。所有方法使用相同任务分布与计费口径，避免把额外计算或数据当作方法收益。

若后期 φ 未提升新学生学习效率，只支持策略自改进；若 ranking 在真实交互中不可靠，优先修复世界模型或缩短想象。标准 LIBERO 保持原有预处理、settle 和 suite step caps，扩展任务与训练恢复单独报告。

Related work

Agima · 交替动作与 imagined observations；task reward 优化想象轨迹。

RISE · world model、value 与 advantage-conditioned policy training；其策略自改进循环冻结 dynamics / value。

Rollback · 经验回溯、反事实分支、树监督与世界模型—策略共同改进。

ThinkingVLA · 统一视觉与语言推理并生成机器人动作。交替生成和分支本身不是本项目独有贡献。

结果、可训练性、物理可信度及新颖性均有待实现和实验验证；这里的公式与模块是研究提案。
