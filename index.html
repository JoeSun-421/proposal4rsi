PROJECT PROPOSAL / 01

面向 Capability Discovery 的 Embodied RSI

让机器人从失败中发现完成任务所缺少的条件，提出并验证新的 preparatory action，并持续改进自己发现和学习新能力的方式。

Background & objective

现有 Vision-Language-Action（VLA）models 主要依赖示范学习。面对未覆盖的物理条件或操作失败，模型往往反复调整已有动作，难以主动发现并建立完成任务所需的新条件。想象驱动训练可以扩展经验，但生成的未来可能偏离真实物理，且固定的数据选择流程未必越来越会学习。

项目目标：以 π0.5 为 action backbone，让 agent 从交互中形成 belief state，通过 adaptive imagination 推演可能的 preparatory action，通过环境验证其效果，并学习选择更有价值的探索与训练数据。

Methodology

观察与诊断历史观测、动作、任务
提议与想象生成 candidate preparatory actions 及后果
执行与验证评估干预后的技能表现
学习与再选择更新能力及 exploration policy

controller qφ 根据失败历史选择提议、想象或执行；π0.5 action expert πθ 生成 continuous action chunk；action-conditioned world model Wψ 预测图像与本体状态；effect predictor Eω 估计 downstream skill 的 success rate。想象仅用于候选筛选，real environment feedback 负责验证和校正。

Δenable(h,u,k)=Pπ¯(成功∣h,u,k)−Pπ¯(成功∣h,u0,k)−λC(u)

从匹配状态比较干预与对照，固定 skill evaluation policy 并重复采样。其中 h 为失败历史，u 为 preparatory action，u₀ 为对照，k 为技能，π̄ 为固定的 skill evaluation policy，C 为干预 cost。该信号衡量干预整体效果，不自动证明特定物理原因。

用有效和无效分支训练候选提议；借鉴 Agima 的 adaptive imagination 训练离散决策，借鉴 RISE 的 advantage-conditioned flow matching 更新连续动作。world model 由实际转移数据训练和校正。

RSI 闭环

在训练阶段，控制器额外决定哪些失败状态与候选值得验证、哪些经验进入训练。比较不同选择使同一初始策略更新后的表现，将downstream learning gain用于更新控制器。

Rlearn(e)=Jdev(θe+)−Jdev(θbase+)−λC(e)

e 是探索及数据选择；θ⁺e 与 θ⁺base 分别为所选经验和默认采样经验更新后的策略参数；Jdev 在 development tasks 上衡量表现。

两组使用相同初始权重、interaction budget 和 training steps。后期控制器如果能在保留的新任务上，让同一初始策略用更少交互学得更快，才支持“改进机制本身得到改进”的主张。该闭环为待验证的研究设计。

PROJECT PROPOSAL / 02

实验设计与实施路径

先验证 preparatory action 是否真正提升 skill success rate，再验证 exploration policy 能否跨任务提升学习效率。

Experimental procedure

  1. 基础能力：微调 π0.5，建立抓取、推动、接触等可组合技能；构造 failure trajectories 与 environment transition data。
  2. 发现与验证：从失败快照采集 preparatory action 与对照分支，训练 world model、effect prediction 与候选控制器；测试未见过的条件—技能组合。
  3. 策略自改进：用短想象产生候选、用环境验证关键分支，通过 advantage-conditioned training 动作和控制器，并持续校正 world model。
  4. 递归验证：对比早期与后期控制器，固定相同初始策略、world model、记忆和预算，在 held-out tasks 上比较学习效率。

Required data

数据来源与用途
base demonstrationsLIBERO / π0.5 兼容轨迹：images、proprioception、actions 与 task instructions，用于 action warm-up。
failures & interventions自建仿真轨迹：失败历史、candidate preparatory actions、匹配对照、后续技能结果；包含无效干预。
dynamics transitions实际执行的多视角图像、本体状态和动作，用于训练与校正 Wψ 和 Eω。
held-out tasks按失败机制、物体、工具及目标的组合划分训练 / 开发 / 测试，test set 不参与 meta-training。

标准 LIBERO 不直接提供所有隐藏物理条件及干预标签；需要独立扩展任务与数据采集。初期可采用可控物理代理，真实接触机制需额外建模或真机验证。

Evaluation & baselines

指标：full tasksuccess rate、有效干预率、环境交互次数、想象与训练计算 cost，以及新任务学习曲线和达到目标 success rate 所需的交互量。

对照：原始 π0.5、直接重试 / 固定搜索、外接反思、RISE 风格自改进、Rollback 风格回溯与分支蒸馏；消融干预收益、belief state、真实校正和学习收益。对齐真实交互及计算预算。

标准 LIBERO 测试沿用现有预处理、等待和步数上限；训练中的 snapshot restoration 及额外测试单独统计，扩展任务单独报告。

Related work

Agima · Train an Imaginative Agent：交替想象与动作，并用任务结果学习自适应推理。

RISE · Self-Improving Robot Policy with Compositional World Model：world model 与价值估计驱动策略更新；原实验的自改进阶段冻结模型与价值网络。

Rollback · Experience Backtracking in World Models：从历史状态回溯分支、对比后果并共同改进 world model 和策略。

ThinkingVLA：统一文字、视觉推理与动作生成。图像推理或分支搜索本身并非本提案的独有创新。

本项目拟验证的区别是：以技能可行性为信号发现 preparatory action，再以跨任务学习收益训练经验选择机制。其新颖性与有效性仍需充分实验及文献核查。
