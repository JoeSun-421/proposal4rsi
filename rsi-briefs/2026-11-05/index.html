持续学习 · 优先精读National Taiwan University11 月 3 日 23:41 · 北京时间

CRONOS：机器人不再每轮归零，学习还能继续吗？

CRONOS: Benchmarking Non-Episodic Reinforcement Learning for Robotic Manipulation

把 VLA 的 RL 微调放进共享场景：上一项任务结束后的环境，直接成为下一项任务的起点。论文发现，物体布局和末端位姿漂移会让朴素微调失效；有针对性的复位能缓解问题，并改善未见布局和任务序列上的泛化。

作者报告

4 个场景、16 项任务；研究 OpenVLA 与 SpatialVLA 的非回合式微调。

证据边界 主要证据来自仿真；部分不可恢复场景检测依赖仿真器特权状态，感知版检测仍待验证。

短评 / EDITOR'S NOTE

自我改进的吞吐量，首先受制于能否持续拿到有效试验。这篇把复位成本纳入问题定义，值得优先读；它没有证明机器人会改进自己的学习算法。

对 openpi / LIBERO 实验的启发

可单独建立连续运行实验，记录有效试验数、复位次数与恢复率；LIBERO 标准评测继续保持原协议。

动作损失，应不应该反向训练 VLM？

Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs

分别控制动作 token 监督和动作专家到 VLM 的梯度通路，检验常见的梯度隔离配方。结果表明，隔离的收益依赖训练历史与评测方式；共同训练时，允许梯度回传也能改善机器人操作表现。

作者报告

闭环驾驶路线进度约提升 17%／40%（分别有／无动作 token 监督）；这两个数字不是机械臂成功率。

证据边界 结果针对文中模型、训练配方和任务；不能据此断言所有 VLA 都应取消梯度隔离。

短评 / EDITOR'S NOTE

它回答了物理反馈该更新系统哪一层，是设计自我改进回路时的关键选择。对 π 系模型很有启发，但这是受控训练研究，并非自主发现训练算法的证据。

对 openpi / LIBERO 实验的启发

优先读操控实验与训练历史消融，比较真实闭环收益，避免只凭离线动作预测误差选配方。

自主研究 · 流程生成Sejong University · AIRI11 月 3 日 22:29 · 北京时间

ARPG：让 LLM 设计可学习的 RL 问题

LLMs as MDP Designers: A Dependency-Aware Agentic Framework for Automated Robot Policy Generation

从自然语言任务生成 RL 流程：先按依赖顺序设计状态、动作、奖励与终止条件，再模块化实现仿真环境，并局部验证和纠错。Isaac Sim 实验报告其建模正确性、可执行性及策略生成成功率优于对照方法。

作者报告

聚焦一个常被忽略的失败模式：代码能运行，生成的环境却未必能训练出策略。

证据边界 论文的主要证据是仿真中的自动流程生成；尚不足以证明长期真机学习闭环或递归收益。

短评 / EDITOR'S NOTE

五篇里最接近自动化机器人研究流程的一篇。值得借鉴中间产物和依赖检查；对固定基准评测，agent 应改进策略，不能靠改奖励或终止条件抬分。

对 openpi / LIBERO 实验的启发

把候选改动、训练记录与独立评测结果分开保存，让生成者无法修改验收标准。

RoboTryOn：把人类视频转换成机器人示范

RoboTryOn: Synthesizing Dexterous Robot Demonstrations from Human Videos via Virtual Try-On

保留任务、物体和背景，把人类动作视频转换成目标机器人视频，再用带深度特征的逆动力学模型推断动作标签，供策略训练。重点是缩小灵巧手和双臂任务中的视觉与动作差距。

作者报告

文中未见任务平均成功率约从 2% 到 60%；在所测设置下，达到纯遥操作示范的效果约需三分之一采集成本。

证据边界 没有该新任务的真机示范，不等于整个系统不依赖机器人数据。合成视频的物理与动作一致性仍是关键风险。

短评 / EDITOR'S NOTE

扩展经验供给的价值很高，但当前回路主要由人类视频驱动。若后续能根据机器人失败定向生成并验证新数据，才更接近自主改进的数据飞轮。

对 openpi / LIBERO 实验的启发

先检查生成数据能否改善独立真机评测，而不是只比较视频质量或训练集指标。

ARP：慢速语义推理与快速动作控制异步运行

Asynchronous Robot Policies

让大 VLM 低频更新语义记忆，让轻量动作专家高频控制机器人；训练时主动暴露语义过期和执行延迟，降低异步带来的错位。论文同时报告操控与动态仿真实验。

作者报告

作者报告准静态任务成功率提高 18%、执行耗时减少 20%；摘要未把前者明确写成百分点。动态仿真约为基线的 3–5 倍。

证据边界 不同实验的指标与基线不能混算；异步架构改善响应速度，本身没有证明部署后持续学习。

短评 / EDITOR'S NOTE

它让强模型参与控制时不必拖慢每一步，对提高实验吞吐有帮助。应归为 RSI 的执行基础设施，不应把响应更快直接称作自我改进。

对 openpi / LIBERO 实验的启发

可在独立实验中同时记录推理延迟、动作频率和失败恢复；不要为提高分数改变标准观测或步数上限。
